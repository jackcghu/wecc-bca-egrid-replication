# Replicating the eGRID Calibration Step — Fowlie, Petersen & Reguant (2021)

A partial replication of the plant-level emissions-intensity calibration behind
**"Border Carbon Adjustments When Carbon Intensity Varies across Producers: Evidence
from California"** (Fowlie, Petersen & Reguant, *AEA Papers and Proceedings* 2021),
plus original follow-on analysis exploring what the underlying eGRID data shows
about carbon-intensity heterogeneity across the Western US electricity grid.

> **Original paper:** Fowlie, M., Petersen, C., & Reguant, M. (2021). Border Carbon
> Adjustments When Carbon Intensity Varies across Producers: Evidence from
> California. *AEA Papers and Proceedings*, 111, 401–405.
> [https://doi.org/10.1257/pandp.20211073](https://doi.org/10.1257/pandp.20211073)
>
> **Original replication package:** Fowlie, Petersen & Reguant (2021), deposited on
> openICPSR. [https://doi.org/10.3886/E131024V1](https://doi.org/10.3886/E131024V1)

## What this repo is (and isn't)

This repo reproduces **one step** of the paper's full simulation pipeline: the
eGRID2018 thermal-plant cleaning step (`build/code/eGrid.py` in the original
package), which calibrates plant-level operating costs and emissions intensities —
the raw material the paper's full market-equilibrium model (Figure 1, Table 1) is
built on. It does **not** reproduce Figure 1 or Table 1 themselves, which require
the full simulation pipeline (raw hourly WECC market data + a Julia/JuMP market
model) — see [Scope](#scope) below.

**This repo does not redistribute the original authors' code or data.** The
original replication package is © Fowlie, Petersen & Reguant and deposited under
ICPSR's terms; rather than re-host it, this repo links to it and documents exactly
how to obtain it yourself. Everything in `src/analysis/` is original code written
independently for this exercise, run against output generated by the original
`eGrid.py` script (which you obtain separately — see [Reproducing](#reproducing)).

## Findings

Five outputs, comparing this replication's numbers against figures explicitly
stated in the paper.

### 1–2. Plant counts and rate distribution by region

577 California plants, 253 Northwest, 283 Southwest, 189 Rockies (plus 5
unmatched to any of the four model regions). Every region shows a large gap
between mean and median emissions rate — a right-skewed distribution driven by a
handful of extreme outliers (see #3).

→ [`results/01_plant_counts_and_distribution.csv`](results/01_plant_counts_and_distribution.csv)

### 3. Outlier drill-down

The most extreme rates trace back to peaker plants that barely ran all year — e.g.
a 24.9 MW California gas plant that generated just 5.0 MWh in the full year,
producing an inflated intensity because the denominator (output) is near zero.
Real-world data quirk, not a pipeline error.

→ [`results/02_outlier_drilldown.csv`](results/02_outlier_drilldown.csv)

### 4. Generation-weighted vs. simple regional average

Weighting each plant's rate by actual annual generation (rather than treating
every plant equally) gives the economically meaningful comparison:

| Region | Weighted avg (tonnes CO₂/MWh) | Paper benchmark |
|---|---|---|
| California | **0.437** | California's own default import rate: **0.428** |
| Southwest | **0.685** | Paper: eGRID nonbaseload intensity "above 0.7" |
| Rockies | **0.828** | Paper: eGRID nonbaseload intensity "above 0.7" |
| Northwest | **0.781** | — |

California's weighted average lands close to the state's own regulatory default
rate — a coincidental but reassuring magnitude check, since that default was
calibrated from different (2006–2008, out-of-state) data. The Southwest and
Rockies figures line up with the paper's explicit statement about nonbaseload
intensities in those regions.

→ [`results/03_weighted_vs_simple_average.csv`](results/03_weighted_vs_simple_average.csv)

### 5. Fuel-type breakdown by region

Explains *why* the weighted averages diverge from the simple ones: coal supplies
a disproportionately large share of real generation (not just plant count) in the
Northwest and Rockies, and coal's per-MWh rate is consistently far higher than
gas's everywhere. This is the concrete mechanism behind the paper's central
claim — that out-of-state producers (especially coal-heavy regions) are
meaningfully dirtier than California's largely gas-fired fleet, which is exactly
the heterogeneity that makes a single flat BCA benchmark contentious.

→ [`results/04_fuel_breakdown_by_region.csv`](results/04_fuel_breakdown_by_region.csv)

## Reproducing

1. **Get the original build step.** Download `build/code/eGrid.py` (+ its small
   `get_path.py` helper) and `build/input/egrid2018_data_v2.xlsx` from the
   [original replication package](https://doi.org/10.3886/E131024V1) on openICPSR
   (project 131024) — you only need the eGRID Excel file, not the full raw dataset.
2. **Run it** (from a project root containing `build/input/` and `build/output/`):
   ```bash
   pip install pandas openpyxl
   python build/code/eGrid.py
   ```
   This produces `build/output/eGrid2018_thermal.csv`.
3. **Clone this repo** alongside that `build/` folder, then run the analysis:
   ```bash
   pip install pandas numpy
   bash src/analysis/run_all.sh
   ```
